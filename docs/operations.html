Operations

Keep the signal useful

Privacy by default

Raw events and physical and logical locations are excluded by default. Backfill selects an allowlist of top-level alert fields.

Least-privilege paths

The Function uses managed identity for storage, queue receive, and DCR publishing. Sending is separately authorized by SAS or a service connection.

Watch the queue

Inspect dead-letter messages, Service Bus metrics, and Function traces. Enable operational panels in the workbook when needed.

Deduplicate queries

Use EventId to account for retries. The workbook shows the latest event by repository, alert, and branch.

A deduplicated starting query

GHASAlerts_CL
| where TimeGenerated > ago(7d)
| summarize arg_max(TimeGenerated, *) by EventId
| project TimeGenerated, ProjectName, RepositoryName, Severity, State, AlertUrl
| order by TimeGenerated desc
