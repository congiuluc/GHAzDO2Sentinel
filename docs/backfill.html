Active-alert backfill

Backfill active alerts

The backfill utility lists project repositories, follows alert continuation tokens, and enqueues returned alerts whose state is Active. Closed and dismissed alerts are not imported.

$env:AZDO_ORG_URL = 'https://dev.azure.com/<organization>'
$env:AZDO_PROJECT_ID = '<project-id>'
$env:AZDO_ACCESS_TOKEN = '<pat>'
$env:SERVICEBUS_FULLY_QUALIFIED_NAMESPACE = '<namespace>.servicebus.windows.net'
$env:SERVICEBUS_QUEUE_NAME = 'ghas'
dotnet run --project .\src\Ghas.Sentinel.Backfill

The backfill uses DefaultAzureCredential. The selected Azure identity needs Azure Service Bus Data Sender on the queue, and the Azure DevOps token needs access to list repositories and Advanced Security alerts. Initial-load events use deterministic IDs.
