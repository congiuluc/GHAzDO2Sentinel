# Security Policy

## Reporting a vulnerability

Please do not report suspected vulnerabilities or exposed credentials in public issues or pull requests.

Use **Security > Advisories > Report a vulnerability** in the GitHub repository if private vulnerability reporting is enabled. Otherwise, contact a repository maintainer privately through a trusted channel. Include the affected component, reproduction steps, and potential impact, but do not send live credentials or sensitive alert data.

If a credential has been exposed, revoke or rotate it promptly; removing it from a commit does not invalidate it.
